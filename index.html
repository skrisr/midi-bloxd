WORLD CODE 生成ツール

MIDI を Bloxd の演奏に変換する

MIDIファイルをアップロードすると、Bloxd.io の World Code / Code Block 用スクリプトに自動変換します。効果音の再生速度(rate)を音程としてずらすことで、note系サウンドを楽器代わりに鳴らします。

01

World Code を貼る（最初に一度だけ）

これは曲を再生するための共通エンジンです。F8でWorld Codeエディタを開き、下のコードをそのまま貼り付けてください。曲を変えてもここは書き換える必要はありません。

02

MIDIをアップロード

.mid / .midi ファイルを選ぶと自動的に変換されます。演奏に使う効果音や基準の音の高さはあとから調整できます。

ノート数: 0 長さ: 0秒 コード文字数: 0
03

スタート用ブロックに貼る

曲データと開始処理が入っています。Bloxdのワールドで新しいCode Blockを置き、下のコードをそのまま貼り付けてください。プレイヤーがそのブロックをクリックすると曲が最初から再生されます。曲ごとに別のブロックを用意すれば複数曲を切り替えられます。

rateは0.5〜4の範囲しか指定できないため、基準ノートからおよそ2オクターブ以上離れた音は自動的に上下オクターブをずらして近似しています。

api.playSound / api.broadcastSound の rate引数で音程を、World Codeのtickコールバック(20回/秒)で再生タイミングを制御しています。仕様はコミュニティのcode-api docsに基づくため、Bloxdのアップデートで挙動が変わる可能性があります。
