WORLD CODE 生成ツール

音声・動画・MIDI を Bloxd の演奏に変換する

音声ファイル（mp3 / wav など）や動画ファイル（mp4 / webm など）をアップロードすると、ブラウザ内で音程を解析して MIDI に変換し、そのまま Bloxd.io の World Code / Code Block 用スクリプトにします。MIDIファイルを直接読み込むこともできます。効果音の再生速度(rate)を音程としてずらすことで、note系サウンドを楽器代わりに鳴らします。

01

World Code を貼る（最初に一度だけ）

これは曲を再生するための共通エンジンです。F8でWorld Codeエディタを開き、下のコードをそのまま貼り付けてください。曲を変えてもここは書き換える必要はありません。

02

音声・動画・MIDIをアップロード

音声・動画ファイルを選ぶと、音程を解析して MIDI に変換し、自動的に Bloxd 用コードまで作ります。.mid / .midi を選んだ場合は解析せずそのまま変換します。ファイルはあなたのブラウザの中だけで処理され、外部には送信されません。

// 音声・動画の解析設定（MIDIファイルを読み込む場合は無関係です）

長い動画は、解析する範囲を区切ると速く安定します。ドラムや歌声が混ざった曲は、音程の取りこぼしや誤検出が出やすくなります（同時に拾う音の数を減らし、感度を調整してください）。

// 変換設定（MIDI → Bloxd）
ノート数: 0 長さ: 0秒 コード文字数: 0
03

曲データを読み込みブロックに分けて貼る

1つのCode Blockに貼れる文字数には上限があるため（実測ではおよそ32,000文字あたりが目安）、曲データは自動的に複数ブロックに分割されます。Bloxdのワールドでパートの数だけCode Blockを並べて置き、パート1から順番に1回ずつクリックして曲データを読み込ませてください（あとから曲を変える場合もパート1から貼り直せばOKです）。

rateは0.5〜4の範囲しか指定できないため、基準ノートからおよそ2オクターブ以上離れた音は自動的に上下オクターブをずらして近似しています。

04

スタート用ブロックに貼る（最初に一度だけ）

読み込み済みの曲データを最初から再生する処理です。別のCode Blockを1つ置いて貼ってください。曲を変えても、このブロック自体は書き換える必要はありません。

api.playSound / api.broadcastSound の rate引数で音程を、World Codeのtickコールバック(20回/秒)で再生タイミングを制御しています。仕様はコミュニティのcode-api docsに基づくため、Bloxdのアップデートで挙動が変わる可能性があります。音声・動画の音程解析はFFTによる簡易的な方式で、市販の採譜ソフトほどの精度はありません。
